# Inventions and the World Wars — interactive picture

Free, responsive interactive hotspot image for GitHub Pages and Google Sites.

## Publish on GitHub Pages
1. Sign in at https://github.com and create a **public** repository, for example `world-war-inventions`.
2. Choose **Add file → Upload files** and upload `index.html` and `background.png` from this folder (not the ZIP itself).
3. Commit the files.
4. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)` and click **Save**.
5. Once GitHub Pages has deployed, open `https://YOUR-USERNAME.github.io/world-war-inventions/` (replace YOUR-USERNAME and repository name if different).

## Embed in Google Sites
Open your Google Site, select **Insert → Embed → By URL**, paste your published GitHub Pages URL, click **Insert**, and resize the embedded frame. For best readability, use a wide frame. Publish the Google Site.

## Edit the pop-ups
Open `index.html` in a text editor. Each item in the `items` array has a `title`, `text`, and coordinates `x` and `y` (percentages of the image). Commit the edited file to GitHub to update the published page.

Note: This is an educational overview. The Internet and GPS are Cold War developments, not World War I inventions.
